# Terminal Portfolio

Interactive terminal-style portfolio for backend developers.

## Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Commands

Type in the terminal:
- `help` - Show all commands
- `about` - About me
- `skills` - Technical skills
- `experience` - Work experience
- `projects` - Projects
- `contact` - Contact info
- `theme` - Change theme
- `clear` - Clear screen

## Tech

- Next.js 16
- TypeScript
- Tailwind CSS v4
- React 19
